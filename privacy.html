Privacy policy

Developer Recovery · Updated October 4, 2026

Purpose and data

Developer Recovery is the owner's personal backup utility. It processes selected local development files, application records, and agent workspace files to create encrypted backups. Selected records may contain personal information or application credentials. Those records are encrypted locally before transfer to the owner's Google Drive account.

Google Drive access

The utility requests Google Drive authorization to create, read, and verify encrypted backup snapshots and recovery instructions. The requested Google permission can cover all Drive files because it must access an existing backup repository created by an earlier OAuth client. The configured backup commands target the designated recovery folder and do not intentionally read unrelated Drive content.

Storage and disclosure

OAuth credentials and authorization tokens are stored in private local configuration files. The backup password is kept separately from Google Drive. Google Drive receives encrypted backup data and recovery instructions that include repository identifiers but no password. External-drive backups are also encrypted.

The utility does not sell data, use it for advertising, or send it to an application server. It does not use backup contents to train AI models. It is not offered as a service to other users. Google provides the cloud storage service under its own policies. GitHub Pages hosts these public information pages.

Retention and control

Snapshots are retained until the owner chooses to remove them. Automatic snapshot deletion is disabled. The owner can stop scheduled backups, revoke the Google connection through Google Account settings, and remove stored backups from their own drive or Google Drive. Revoking access does not itself delete existing backups. Loss of the separately stored backup password can prevent recovery.

Contact and changes

The owner maintains this utility and can update this policy when its behavior changes. Contact the owner through the GitHub profile.
